## 作品要点

- 自研向量存储引擎：列式行镜像 + 预写日志 + 崩溃恢复 + IVF 倒排精确剪枝，编译期依赖为空。
- Recall@10 = 1.000（有过滤与无过滤），由剪枝构造保证而非调参获得。
- 查询耗时 900.6 ms / 1000 次 TopK，查询 I/O 1.611 MB（相对基线版本 I/O 降低 4.58 倍）。
- 单元与协议测试 158 项全部通过；官方判题器本地 20/20 PASS；12 轮 SIGKILL 崩溃恢复幂等。

详细方案见 `作品设计文档.docx`。
