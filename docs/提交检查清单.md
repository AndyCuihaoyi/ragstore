# 提交检查清单

> 打包上传前逐项核对。依据 [赛事要求](./赛事要求.md)，含初赛网络评审与决赛答辩两个阶段的要求。

## A. 作品内容（自由赛道）

- [ ] 作品内容以**存储技术与应用设计**为主，非存储内容不喧宾夺主
- [ ] 研究领域与信息存储强相关（AI4Storage / Storage4AI / 全闪集群 / 分布式 / 云与边缘 / 绿色存储 / DNA 存储 / 存储安全与隐私）
- [ ] 作品形态明确（软件 / 硬件 / 软硬结合）

## B. 五项必交文档

> 章节落位与排版细节见 [文档模板结构](./文档模板结构.md)。

### 1. 作品设计方案

- [ ] 功能
- [ ] 指标
- [ ] 实现原理
- [ ] 硬件框图
- [ ] 软件流程

### 2. 作品测试方案

- [ ] 测试设备
- [ ] 测试数据
- [ ] 结果分析
- [ ] 实现功能
- [ ] 特色

### 3. 创新性说明

- [ ] **独立成章**（模板三章中无对应章节，建议新增「第四章 创新性说明」）
- [ ] 对应评审维度「作品方案的原创性与创新性」，与既有方案的差异点明确
- [ ] 说明对「AI4Storage / Storage4AI」类前沿方向的结合或借鉴

### 4. 其他文档

- [ ] 源码 / 可运行程序 / 演示脚本
- [ ] 架构图、时序图等设计图
- [ ] 测试数据原始文件与日志

### 5. 参赛作品声明

- [ ] 版权归属声明
- [ ] 技术公开说明
- [ ] 已签署**作品原创性声明**（`templates/作品原创性声明.docx`）
- [ ] 声明中的作品名称空处已填，且与封面、README、压缩包内目录完全一致
- [ ] 全员手写签名 + 日期

## C. 已发表成果的附加要求（若适用）

- [ ] 提交**两页摘要**
- [ ] 提交**论文全文**
- [ ] 明确注明原发表的**会议或期刊名称**
- [ ] 明确注明**卷期**
- [ ] 明确注明**发表时间**

## D. 评审视角自检

### 初赛（网络评审）

- [ ] 原创性与创新性 —— 是否一看即知与常见方案的差异
- [ ] 完成程度 —— 系统是否真正可跑、指标是否可复现
- [ ] 性能 —— 有量化数据与对比基线
- [ ] 应用价值 —— 解决的真实痛点清楚
- [ ] 文档规范性 —— 结构完整、图表规范、术语统一

### 决赛（现场答辩）

- [ ] 演示脚本 / Demo 流程已准备（离线可跑）
- [ ] 架构与原理可在 5 分钟内讲清
- [ ] 关键指标与测试数据能当场解释来源
- [ ] 预设问答：技术选型、对比基线、局限与后续工作

## E. 打包与上传

- [ ] 文件名严格为 `Freetrack-<华为云账号>.zip`（自由赛道固定前缀 `Freetrack`）
- [ ] 华为云账号与队长账号完全一致，无多余空格 / 中文 / 大小写错误
- [ ] 压缩包大小 **< 500 MB**（`python scripts/check_submission.py <包.zip> --naming '^Freetrack-.+\.zip$' --max-size-mb 500` 可自动确认）
- [ ] 解压测试：解压后能正常打开、可运行
- [ ] 编码无乱码（文档建议 UTF-8，图片/字体随包提供）
- [ ] 模板文件本身已填写完整并包含在包内
- [ ] 上传次数 ≤ 10（每次上传前确认内容完整，避免浪费次数）
- [ ] 最终以**最后一次**提交为准 —— 上传后重新下载校验一遍

## F. 文档格式合规（模板硬性要求）

排版参数以官方模板实测值为准，详见 [文档模板结构](./文档模板结构.md)。

- [ ] 从 `templates/作品设计文档模板.docx` **复制**一份填写，原模板文件保持不动
- [ ] A4 纸，页边距上下 2.54 cm、左 2.86 cm、右 2.59 cm
- [ ] 除标题外，**正文全部宋体、小四（12 pt）、1.5 倍行距**
      （模板 Normal 默认是五号 10.5 pt，需手动统一改掉）
- [ ] 西文与数字用 Times New Roman
- [ ] 三章标题下的斜体「（建议包括：……）」提示文字**已全部删除**
- [ ] 「填写说明」整页**保留未删**
- [ ] 页脚页码正常显示（奇数页「第 X 页 共 Y 页」）
- [ ] 图表编号连续、图题在图下表题在表上、引用可对应
- [ ] 无空白页、无「错误!未找到引用源。」之类的域错误
- [ ] 全文在 A4 下打印预览无溢出、无孤行寡行
