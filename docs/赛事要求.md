# 赛事要求

> 来源：赛事官方页面「赛题详情 / 评选规则 / 作品提交要求」章节，2026-11-26 整理。

## 一、赛题详情（自由赛道）

自由赛道参赛作品可以是软件、硬件等。参赛作品的内容以**存储技术与应用设计**为主要内容。

参赛作品所属研究领域应与信息存储领域强相关，包括但不限于：

- AI4Storage
- Storage4AI
- 全闪集群存储
- 分布式存储
- 云与边缘存储
- 绿色存储
- DNA 存储
- 存储安全与隐私
- 其他与信息存储强相关的主题

### 提交物清单（至少包括）

按照自由赛道题目及文档模板要求，提交的作品至少包括如下内容：

| # | 文档 | 必须涵盖的内容 |
| --- | --- | --- |
| 1 | 作品设计方案 | 功能、指标、实现原理、硬件框图、软件流程 |
| 2 | 作品测试方案 | 测试设备、测试数据、结果分析、实现功能、特色 |
| 3 | 创新性说明 | — |
| 4 | 其他文档 | 除上述规定文档以外的其他作品相关资料 |
| 5 | 参赛作品声明 | 版权、技术公开 |

> 官方模板（页面底部下载）：`作品设计文档模板.docx`（18.36 KB）、`作品原创性声明.docx`（21.66 KB），均为 2026-07-31 上线。

## 二、评选规则

### 初赛评审方式

组委会在全国范围内组织专家对参赛队伍提交的作品进行**网络评审**。依据网络评审结果，由专家组评审并最终确定 **16 强** 进入决赛的名单。

> 进入决赛的参赛队伍数量由专家组根据参赛队伍总数及参赛作品质量确定。

评审维度：

| 赛道 | 评审主要内容 |
| --- | --- |
| 挑战赛道 | 代码测试的正确性、性能、应用价值 |
| **自由赛道** | 作品方案的**原创性与创新性**、作品**完成程度**、作品的**性能**、作品的**应用价值**、相关文档的**规范性** |

### 决赛评审方式

| 赛道 | 评审方式 |
| --- | --- |
| 挑战赛道 | 代码作品测试的正确性、性能 + 答辩专家评分 |
| **自由赛道** | **现场答辩**专家评分 |

## 三、作品提交要求

鼓励对新型存储系统设计与实现的创新探索，以及系列研究成果的经验分享。成果包括**已发表工作**、**Working-in-Progress 工作**等。

投稿内容如为计算机存储领域已发表的研究成果，需提交两页摘要与论文全文，且必须在材料中明确注明原发表的会议或期刊名称、卷期、发表时间等关键信息。

### 1. 作品命名要求

- 格式：`赛题名称-华为云账号.zip`
- 自由赛道固定为 `Freetrack`
- 大小：**< 500 MB**
- 示例：队长华为云账号为 `hid_abcd` → `Freetrack-hid_abcd.zip`

### 2. 原创性要求

每个参赛队伍需签署**原创性说明**，并与参赛作品一并提交。

### 3. 作品提交次数

自由赛道参赛阶段仅可上传 **10 次**作品，**以最后一次提交为准**。
