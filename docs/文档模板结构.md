# 文档模板结构

> 依据官方模板实测解析（2026-11-26），与 [赛事要求](./赛事要求.md) 配套使用。

## 一、作品设计文档模板.docx

### 封面（首页）

标题：**2026年全国大学生信息存储技术竞赛 / 设计文档**

需填写的字段：

| 字段 | 填写内容 |
| --- | --- |
| 赛题名称 | `Freetrack`（自由赛道固定） |
| 队伍名称 | 团队名称 |
| 电子邮箱 | 队长邮箱 |
| 提交日期 | 提交当日 |

### 填写说明（第 2 页，**此页不删除**）

原文四条：

1. 所有参赛项目必须为一个基本完整的设计。设计文档旨在能够清晰准确地阐述该参赛队的参赛方案。
2. 设计文档采用A4纸撰写。除标题外，所有内容必需为宋体、小四号字、1.5倍行距。
3. 设计文档中各项目说明文字部分仅供参考，设计文档撰写完毕后，请删除所有说明文字。(本页不删除)
4. 设计文档模板里已经列的内容仅供参考，作者可以在此基础上增加内容或对文档结构进行微调。

> 第 3 条的**执行方式**：每个章节标题下的灰色斜体「（建议包括：……）」在定稿前全部删除，**填写说明整页保留**。

### 正文三章（heading 1 样式）

| 章节 | 官方建议内容 | 建议映射到 |
| --- | --- | --- |
| 第一章 方案设计 | 整体设计架构、设计原理介绍、图示等 | 功能 / 指标 / 实现原理 / 硬件框图 / 软件流程 |
| 第二章 关键代码说明 | 具体编程实现过程：编程语言、框架、库等 | 关键代码与工程实现说明 |
| 第三章 测试及分析 | 环境配置、关键测试/调试过程、关键指标结果及分析 | 测试设备 / 测试数据 / 结果分析 / 实现功能 / 特色 |

### 排版参数（实测）

| 项 | 值 |
| --- | --- |
| 页面 | A4，210×297 mm（11906×16838 twips） |
| 页边距 | 上 2.54 cm ／ 下 2.54 cm ／ 左 2.86 cm ／ 右 2.59 cm |
| 默认字体 | 中文 SimSun（宋体），西文 Times New Roman |
| Normal 样式实际字号 | 10.5 pt（五号）⚠️ 与「小四号」要求不一致 |
| Heading 1 | 22 pt 加粗 |
| Heading 2 | 16 pt 加粗 |
| 页脚 | 奇数页「第 X 页 共 Y 页」，偶数页为页码 |
| 参考篇幅 | 模板渲染约 7 页 |

> ⚠️ **常见扣分点**：模板 Normal 是五号（10.5 pt），但说明要求**小四（12 pt）+ 1.5 倍行距**。正文定稿前需手动统一设置，不要依赖模板默认值。
> ⚠️ 参考篇幅 7 页是模板自身的体量，实际作品应按内容需要展开，建议设计文档正文控制在 15–30 页。

### 五项必交文档 → 模板章节落位

| 官方必交项 | 落位 |
| --- | --- |
| 1. 作品设计方案 | 第一章 方案设计 + 第二章 关键代码说明 |
| 2. 作品测试方案 | 第三章 测试及分析 |
| 3. 创新性说明 | **模板无对应章节**，需自行新增（建议第四章 创新性说明，或并入第一章 1.x 节） |
| 4. 其他文档 | 附录 + 压缩包内文件 |
| 5. 参赛作品声明 | 独立的《作品原创性声明.docx》 |

> 第 3 项是唯一的结构缺口。评审把「原创性与创新性」列为自由赛道初赛首要维度，建议独立成章而非一笔带过。

## 二、作品原创性声明.docx

### 结构

1. 标题：**作品原创性声明**
2. 正文（唯一需填空处）：

   > 本参赛团队郑重声明：本团队在第四届全国大学生信息存储技术竞赛所提交的作品 **＿＿＿＿＿＿**，是团队同学在指导老师的指导下，独立进行研究工作所取得的真实研究成果，从创意到实现均为原创。除作品中已经标注引用的内容外，本参赛作品不包含任何其他个人或集体已经发表或撰写过的研究成果。本团队及作品严格遵守 2026年全国大学生信息存储技术竞赛组委会颁布的《第四届全国大学生存储竞赛参赛指南》相关规定，并且无侵害他人合法权益行为和违反相关法律法规行为。本团队对作品拥有完整、合法的著作权及其他相关权益。本声明的法律结果由本参赛团队承担。

3. 结尾字段：**作品参赛团队组员（签名）：** ／ **年　　月　　日**

### 排版参数（实测）

| 项 | 值 |
| --- | --- |
| 页面 | A4，210×297 mm |
| 页边距 | 上 2.54 cm ／ 下 2.54 cm ／ 左 3.17 cm ／ 右 3.17 cm |
| 正文字号 | 12 pt（小四）✅ 已符合要求 |
| 行距 | 固定值 20 pt（约 1.5 倍）✅ 已符合要求 |
| 页眉 / 页脚 | 均为空 |

### 填写要点

- 作品名空处填**完整作品名称**（与压缩包、README、设计文档封面保持完全一致）
- 全员手写签名后扫描或打印签字拍照，作为独立文件放入压缩包
- 若作品包含已发表成果，需在「除作品中已经标注引用的内容外」处对应标注引用来源（会议/期刊名称、卷期、发表时间）
- 文档中出现的是「**第四届全国大学生信息存储技术竞赛**」，与赛事名称一致，无需修改

## 三、模板使用顺序

1. 复制 `templates/作品设计文档模板.docx` → `作品设计文档.docx`（**保留原模板不动**）
2. 填封面四个字段 → 保留「填写说明」页 → 删除三章下的斜体提示文字
3. 按第一/二/三章 + 第四章 创新性说明撰写正文，统一宋体小四 1.5 倍行距
4. 填「作品原创性声明.docx」的名称空处与签名
5. 两个 docx 连同源码、测试数据、演示材料一起压缩为 `Freetrack-<华为云账号>.zip`
